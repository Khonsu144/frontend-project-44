## Games Collection

A collection of five command-line math games for brain training.

### Available Games

#### 1. Brain Even
[![asciicast](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_EVEN.svg)](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_EVEN)

Determine if a number is even. Answer "yes" for even numbers, "no" for odd numbers.

#### 2. Brain Calc
[![asciicast](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_CALC.svg)](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_CALC)

Solve simple arithmetic expressions with +, -, * operators.

#### 3. Brain GCD
[![asciicast](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_GCD.svg)](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_GCD)

Find the greatest common divisor of two numbers.

#### 4. Brain Progression
[![asciicast](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_PROGRESSION.svg)](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_PROGRESSION)

Find the missing number in an arithmetic progression.

#### 5. Brain Prime
[![asciicast](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_PRIME.svg)](https://asciinema.org/a/ВАШ_ИДЕНТИФИКАТОР_PRIME)

Determine if a number is prime. Answer "yes" for prime numbers, "no" for composite numbers.
